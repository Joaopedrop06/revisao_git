Git & VS Code

Guia rápido com os principais comandos Git e atalhos essenciais do Visual Studio Code.

Git — básico

git initCria um novo repositório.
git clone URLBaixa um repositório remoto.
git statusMostra o estado dos arquivos.
git log --onelineExibe o histórico resumido.
git diffMostra alterações ainda não preparadas.

Git — fluxo de trabalho

git add .Prepara todas as alterações.
git commit -m "mensagem"Registra as alterações.
git branch nomeCria uma branch.
git switch nomeTroca de branch.
git merge nomeUne uma branch à atual.
git pullBaixa e integra mudanças remotas.
git push origin nomeEnvia commits para o remoto.

Git — desfazer e guardar

git restore arquivoDescarta alterações locais no arquivo.
git reset HEAD arquivoRemove o arquivo da área de stage.
git revert HASHDesfaz um commit com segurança.
git stashGuarda alterações temporariamente.
git stash popRecupera alterações guardadas.
git tag v1.0.0Cria uma marcação de versão.

VS Code — navegação

Ctrl + PAbrir rapidamente um arquivo.
Ctrl + Shift + PAbrir a Paleta de Comandos.
Ctrl + Shift + FPesquisar em todos os arquivos.
Ctrl + `Abrir ou fechar o terminal.
Ctrl + BMostrar ou ocultar a barra lateral.

VS Code — edição

Ctrl + DSelecionar a próxima ocorrência.
Alt + ↑ / ↓Mover a linha para cima ou baixo.
Shift + Alt + ↓Duplicar a linha.
Ctrl + /Alternar comentário de linha.
Shift + Alt + FFormatar o documento.
Ctrl + SSalvar o arquivo.

VS Code — visualização

Ctrl + + / -Aumentar ou reduzir o zoom.
Ctrl + WFechar o editor atual.
Ctrl + \Dividir o editor.
Ctrl + K, ZAtivar o modo Zen.
Atalhos para Windows/Linux. No macOS, substitua Ctrl por Cmd quando aplicável.
